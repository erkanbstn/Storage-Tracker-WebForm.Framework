# Teknik servis

Teknik servis kayıtlarını tutan web formu.

## Ne var

Sayfalar DevExpress teknik servis projesindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Web Forms, Entity Framework ve DevExpress.
